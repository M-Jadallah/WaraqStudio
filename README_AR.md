# ورق — Waraq Studio

تطبيق Windows محلي لتحويل فيديوهات YouTube أو ملفات الصوت إلى تفريغ، ثم إلى مستند Word مستقل لكل مهمة عبر OpenCode.

## التشغيل

افتح `Start.cmd` أو `Windows/WaraqStudio/WaraqStudio.exe`. احتفظ بمجلد `_internal` بجانب الملف التنفيذي؛ هذه حزمة مجلد وليست EXE منفردًا.

لا يحتاج الإصدار المجمع إلى تثبيت Python. يحتاج تنزيل YouTube إلى اتصال إنترنت وJavaScript runtime مناسب مثل Node.js أو Deno. تحتاج معالجة Word إلى OpenCode وإعداد مزوّد النموذج وتسجيل الدخول فيه، ومهارة التنسيق المستخدمة. هذه الأدوات وحساباتها لا تُضمّن داخل التطبيق.

أول تشغيل:

1. افتح «الإعدادات» ثم «استيراد إعدادات السكربت»، واختر ملف settings.json القديم إذا أردت استيراده. يُستورد مفتاح Deepgram إلى العامل الأول في مخزن Windows الآمن، ولا يُنسخ إلى إعدادات التطبيق.
2. افتح «العمال والخدمات»: خمسة عمال Deepgram افتراضيًا لكل واحد مفتاحه ومعرّف مشروعه، وخمسة عمال OpenCode لكل واحد مزوّده ونموذجه ومستوى تفكيره. أدخل مفتاح كل عامل يحتاج مفتاحًا من نافذة إعداداته، ويمكنك إيقاف استقبال أي عامل بمفتاح التفعيل في صفه مباشرة.
3. راجع نموذج OpenCode ومزوّده والوكيل والبرومبت، وحدد مجلد النتائج ومجلد المكتبة. عند الحاجة اختر ملف كوكيز Netscape يدويًا.
4. أضف رابطًا، واقرأ الفيديوهات، وحدد المطلوب أو نطاقًا مثل `5-12,18`. أعد ترتيبها بأزرار الأعلى والأسفل.
5. اختر قالب البرومبت ومراحل المعالجة، وأضف المهام إلى الطابور، ثم اضغط «تشغيل الطابور».

لا يبدأ التطبيق طلبات مدفوعة تلقائيًا عند فتحه. الاستيراد لا يعدّل السكربت القديم أو إعداداته أو كوكيزه.

## سير العمل

- عامل تنزيل واحد على مستوى التطبيق؛ تشارك قراءة المصادر معه قفل اتصال YouTube.
- خمسة عمال Deepgram افتراضيًا، لكل واحد مفتاحه ومعرّف مشروعه المستقل (فيأخذ الخمسة حصصًا مستقلة). يمكن إضافة حتى 16 عاملًا وضبط حد مشترك للمشروع، ويُوقف أي عامل عن استقبال المهام بمفتاح التفعيل في صفه أو من نافذة إعداداته.
- خمسة عمال OpenCode افتراضيًا، ولكل عامل مزوّده ونموذجه ومستوى تفكيره، ومجلد عمل مستقل لكل مهمة.
- ترتيب التنزيل يتبع ترتيب الاختيار الظاهر. أرقام الدروس الأصلية لا تتغير عند إعادة الترتيب.
- في الوضع العادي يبدأ العامل أول مهمة جاهزة؛ قد تختلف أوقات الانتهاء. الوضع الصارم ينتظر اكتمال المرحلة نفسها للمهام السابقة في الدفعة.
- يمكن استيراد TXT للانتقال مباشرة إلى Word، أو صوت محلي لتجاوز YouTube. يُحوّل الصوت المحلي غير MP3 قبل إرساله.

قوالب المصدر: الدورة الكاملة، تنزيل وتفريغ، تنزيل فقط، أو قالب مخصص من الإعدادات. لا يُسمح بتعطيل مرحلة يحتاجها الناتج اللاحق دون توفير مدخل محلي مناسب.

قوالب البرومبت: تُدار من «الإعدادات» ← «قوالب البرومبت». لكل قالب اسم ونص تعليمات يُرسل إلى OpenCode (توجيه لمهارة معينة وتعليمات إضافية)، ويُختار القالب عند إضافة المهام من قائمة «قالب البرومبت». يجب أن يحوي كل قالب `{transcript_path}` و`{output_path}`. يُحفظ القالب المختار داخل لقطة المهمة، فتعديل قالب لاحقًا يؤثر في المهام الجديدة فقط.

## مزودو OpenCode وعزل ملفات العمال

خمسة عمال OpenCode، ولكل واحد مزوّده ونموذجه ومستوى تفكيره من «العمال والخدمات» ← «إعدادات»:

- **تسجيل دخول OpenCode**: يستخدم الجلسة المسجَّلة داخل OpenCode نفسها (اشتراك ChatGPT وغيره) بلا مفتاح، وفي مجلد بيانات OpenCode المشترك.
- **أي مزود آخر** (المدمجون: OpenRouter وOpenAI API وAnthropic وGoogle، أو مزود تضيفه بنفسك): يُشغَّل بمفتاح خاص بالعامل يُحفظ في Windows Credential Manager تحت اسم `معرّف العامل:المزود`، ويُمرَّر إلى OpenCode كمتغير بيئة، وفي **مجلد بيانات مستقل لكل عامل** (`XDG_DATA_HOME` و`XDG_STATE_HOME` تحت «مجلد بيانات عمال OpenCode») حتى لا تتنازع العمليات المتوازية على قاعدة OpenCode المشتركة. عامل بمزود يحتاج مفتاحًا وبلا مفتاح محفوظ لا يستقبل مهامًا، وتظهر له رسالة واضحة في صفحة العمال.

**إضافة مزود يدويًا**: من «العمال والخدمات» ← «المزودون»، أدخل معرّف المزود كما يستخدمه OpenCode (مثل `groq`) والاسم المعروض ومتغير المفتاح (مثل `GROQ_API_KEY`)، واترك «عزل ملفات العامل» مفعّلًا. المزودون المدمجون ثابتون، والمضافون قابلون للتعديل والحذف (ولا يُحذف مزود يستخدمه عامل).

معرّف النموذج يُركَّب تلقائيًا: مزود `groq` مع `llama-3.3-70b` يُرسل كـ`groq/llama-3.3-70b`، ومزود OpenRouter مع `deepseek/deepseek-v4.1-flash` كـ`openrouter/deepseek/deepseek-v4.1-flash`، أما «تسجيل الدخول» فيُرسل النموذج كما كتبته. ومستوى التفكير (`--variant`) يُحذف من الأمر إذا تركت الحقل فارغًا. وللتأكد من معرّفات النماذج المتاحة عندك بعد حفظ مفتاح المزود، شغّل `opencode models` وابحث عن اسم مزودك.

**فرض إعداد عند بدء الطابور**: عند ضغط «تشغيل الطابور» يسألك التطبيق أولًا: تشغيل بالإعداد الافتراضي لكل عامل، أو فرض **مزود ونموذج ومستوى تفكير** على كل عمال OpenCode دفعة واحدة. الفرض لجلسة واحدة ولا يُحفظ، ويمكن تغييره أو إلغاؤه في أي وقت من زر «فرض إعداد على عمال OpenCode» في مركز العمليات (مفيد عند نفاد نافذة الخمس ساعات: بدّل الكل إلى مزود آخر فيتابع الطابور بالعمال أنفسهم). عامل بلا مفتاح للمزود المفروض يُتخطى برسالة صريحة.

## مكتبة الملفات

يمكن إنشاء **مجلد مادة أو درس** من صفحة «إضافة مصدر»، ثم اختياره قبل إضافة الفيديوهات أو الملفات المحلية. ويمكن تغيير مجلد مهمة قائمة من «التفاصيل». تعرض «مكتبة النتائج» و«الملفات» اسم المجلد وخيار التصفية به. تنسخ المكتبة النتائج إلى `اسم المجلد/Word` و`اسم المجلد/التفريغات` و`اسم المجلد/الصوت`؛ تبقى النتائج غير المصنّفة مباشرة داخل مجلدات الأنواع الثلاثة. زر «تصدير Word» في «مكتبة النتائج» ينسخ المستندات إلى مجلد تختاره على جهازك بالبنية نفسها، مع اسم ثابت ومميز لكل مهمة.

نسخة منظّمة من النتائج داخل «مجلد المكتبة» (افتراضيًا `library` في مجلد بيانات التطبيق، ويمكن تغييره من الإعدادات) ضمن مجلد المادة ثم مجلد النوع `Word` أو `التفريغات` أو `الصوت`. تُنسخ الملفات بعد اكتمال كل مرحلة، أو بزر «تنظيم الآن» لنتائجك السابقة. النسخ معيد بلا تكرار: اسم ثابت لكل (مهمة، نوع) محفوظ في سجل `.waraq-library.json`، وتشابه العناوين يُنتج اسمًا مميزًا بدل الكتابة فوق ملف درس آخر، وإعادة معالجة المهمة تُحدّث نسختها. الأصل في مجلد المهمة لا يُمس. خيار «انسخ الصوت أيضًا» معطّل افتراضيًا لأنه يضاعف المساحة.

من «الإعدادات» ← «تحديث yt-dlp» يمكنك جلب أحدث إصدار Windows مستقر رسمي لأداة قراءة YouTube. يتحقق التطبيق من بصمة SHA-256 قبل الاستخدام ويعرض الإصدار الفعال. يلزم اتصال بالإنترنت وJavaScript runtime مدعوم؛ خيار التحديث يعمل على حزمة Windows، وتحديث اعتماديات النسخة المضمّنة يتم عند إعادة بناء التطبيق. خطة التنفيذ والتحقق في `IMPLEMENTATION_PLAN_AR.md`.

صفحة «الملفات» تعرض ما في المكتبة مع تصفية بالنوع (Word / التفريغات / الصوت) وبحث بالاسم، وأزرار: فتح، فتح المجلد، نسخ المسار، وحذف من المكتبة (بتأكيد، ولا يمس الأصل في مجلد المهمة).

## الإعادة التلقائية وحد الاستخدام

أخطاء التنزيل تُصنَّف قبل قرار الإعادة حتى لا يبقى أي توقف بلا سبب ظاهر:

- **تقييد مؤقت (429)**: تهدئة عامة لطلبات YouTube تُحفظ في قاعدة البيانات فتبقى سارية حتى بعد إغلاق التطبيق وفتحه، وتُعاد المهمة تلقائيًا إلى الطابور بموعد بعد انتهاء التهدئة — دون أي تدخل. صف عامل YouTube يعرض الدقائق المتبقية، وتفاصيل المهمة تعرض وقت المحاولة القادمة. الإعادة اليدوية تعيد المهمة إلى الطابور لكنها لا تتجاوز التهدئة حفاظًا على عنوان شبكتك.
- **خطأ عابر** (انقطاع شبكة، مهلة، أخطاء خادم 5xx): يُعاد تلقائيًا بفواصل متزايدة 5 ثم 15 ثم 45 دقيقة. اضبط العدد من الإعدادات (`youtube_retry_attempts` لتنزيل YouTube و`auto_retry_attempts` لـ OpenCode، و0 يعطّل الإعادة). نجاح أي محاولة يصفّر العدّاد، فتبدأ كل توقفة جديدة بميزانية كاملة.
- **خطأ دائم خاص بالفيديو** (محذوف، خاص، مقيّد جغرافيًا أو بحقوق): يفشل مرة واحدة بلا إعادة وبلا إيقاف لبقية تنزيلات الطابور.
- **رفض وصول** (كوكيز ناقصة، تسجيل دخول، تحقق بشري): المهمة تتوقف، وتتوقف خدمة التنزيل آليًا لحماية بقية المهام من نفس الرفض. بعد إصلاح السبب يكفي زر واحد: «إعادة المحاولة» من تفاصيل المهمة أو «إعادة فحص العامل» من صفحة العمال — كلاهما يرفع التوقف الآلي ويعيد المهام المتوقفة إلى الطابور. الإيقاف اليدوي الذي تختاره أنت من زر «إيقاف الخدمة» لا يُلغى ضمنيًا أبدًا.

مرحلة التفريغ المدفوعة لا تُعاد تلقائيًا أبدًا: لها إعادتها الداخلية على أخطاء HTTP المؤقتة مع احترام `Retry-After`، ونتيجة «غير مؤكدة» تبقى تتطلب قرارك حفاظًا على الفوترة.

عند بلوغ حد استخدام اشتراك ChatGPT في OpenCode (نافذة الخمس ساعات، يظهر كخطأ 429 بعبارة usage limit) يُعاد جدولة المهمة كل ساعة حتى خمس محاولات، بينما تستمر بقية المراحل والمهام في العمل. إن استُنفدت المحاولات يظهر فشل نهائي — غالبًا الحد الأسبوعي — وتُنفَّذ بقية المهام طبيعيًا. في تفاصيل المهمة يظهر وقت المحاولة القادمة، وزر «إعادة المحاولة» يتجاوز الانتظار فورًا ويصفّر العدّاد.

الانتظار محفوظ في قاعدة البيانات: إغلاق التطبيق وإعادة فتحه لا يلغي الجدولة، وتُلتقط المحاولة تلقائيًا عند حلول وقتها.

## الإيقاف التلقائي بعد اكتمال الطابور

خيار في مركز العمليات بجانب زر التشغيل: عند تفعيله يُغلق التطبيق نفسه بأمان بعد انتهاء كل المراحل القابلة للتنفيذ. مرحلة منتظرة (بحد استخدام أو غيره) تمنع الإغلاق حتى ينتهي انتظارها؛ والمهام المحجوبة أو المتوقفة تمنع الإغلاق أيضًا حتى تُعالج. الخيار لجلسة واحدة ولا يُحفظ بين التشغيلات.

## الإيقاف والاستئناف

«إيقاف بعد المهام الحالية» يمنع التوزيع الجديد ويترك الطلبات الحالية تكمل. إيقاف الخدمة يوقف توزيع مهام تلك الخدمة فقط. تعطيل عامل يمنعه من استقبال مهمة أخرى.

إلغاء المهمة يحاول إيقاف العمليات المحلية، لكن طلب HTTP المرسل إلى Deepgram قد يستمر لدى الخدمة حتى بعد الإلغاء أو الإغلاق. لا يمكن ضمان إلغاء الفوترة. عند فقدان استجابة Deepgram أو الإغلاق أثناء طلبه تظهر حالة «نتيجة غير مؤكدة»، وتحتاج إعادة المحاولة إلى قرار المستخدم.

إعادة المحاولة تستخدم الاستجابات المحفوظة. إعادة التفريغ أو OpenCode «بنسخة جديدة» تغيّر بصمة المرحلة وتحافظ على الملفات السابقة؛ إعادة التفريغ قد تحمل تكلفة إضافية.

بعد إصلاح كوكيز رفض الوصول: زر «إعادة المحاولة» في تفاصيل المهمة أو «إعادة فحص العامل» في صفحة العمال يرفع التوقف الآلي ويعيد العمل تلقائيًا. نقص المساحة يعمل بالطريقة نفسها بعد تحرير المساحة. أما تقييد 429 فلا يحتاج إجراء: التنزيل يستأنف نفسه بعد التهدئة المحفوظة. البرنامج يقلل الطلبات ولا يضمن عدم تقييد YouTube.

## واجهة مكثفة قابلة للتحكم

القوائم في كل الصفحات مضغوطة لعرض أكبر عدد ممكن من العناصر: صفوف أقصر، هوامش وأزرار أصغر، وشريط علوي واحد مضغوط. التمرير ثابت المكان: أي تحديث للبيانات أثناء التصفح (تقدم مهمة، سجل جديد، عدّاد عامل) لا يعيدك إلى أعلى القائمة — تبقى في موضعك حتى مع طول القائمة.

القائمة الجانبية قابلة للطي بزر أعلاها: عند الانضغاط تصبح أيقونات فقط مع تلميح باسم الصفحة، وتتوسع بالنص كاملًا عند الإعادة، وتُحفظ الحالة مع بقية الإعدادات.

من صفحة الإعدادات يتحكم «حجم الواجهة» في تكبير/تصغير الخطوط والأزرار والصفوف فورًا (80٪ إلى 140٪ بخطوات 5٪) مع زر إعادة للافتراضي، ويُطبَّق على كل الصفحات ويُحفظ تلقائيًا.

## Word وOpenCode

يجب أن يحتوي البرومبت متغيري `{transcript_path}` و`{output_path}`. تتوفر أيضًا `{title}` و`{position}`. الشرط نفسه مطبَّق على كل قالب برومبت في الإعدادات.

`{transcript_path}` يشير إلى نسخة من التفريغ داخل مجلد عمل الوكيل؛ الأصل يبقى في مجلد المهمة خارج نطاق الوكيل وتُتحقق بصمته بعد انتهاء التشغيل. صلاحيات OpenCode الافتراضية ترفض قراءة ما خارج مجلد العمل في التشغيل غير التفاعلي، ولذلك لا يعتمد سير العمل على أي مسار خارجي.

تُنسخ مصادر مهارة `arabic-lesson-formatter-sequential` من مهارات المستخدم، أو النسخة القديمة الموجودة في مجلد المشروع المختار، إلى مساحة المهمة دون نسخ الأسرار أو المدخلات القديمة. تعتمد مكتبات Node على `NODE_PATH` إلى تبعيات المهارة المحلية. لذلك يجب أن تكون المهارة وتبعياتها موجودة على الجهاز المستهدف.

التطبيق يتحقق من:

- وجود ملف DOCX بالمسار المتفق عليه وسلامة ZIP.
- وجود الأجزاء الأساسية للمستند وXML سليم ونص Word قابل للتحرير.
- بقاء بصمة TXT الأصلية دون تغيير أثناء العملية.

هذه فحوص بنيوية؛ لا تعني مراجعة بشرية لدقة التحرير أو مطابقة التنسيق البصري. لا يُفعّل التطبيق الموافقة الشاملة `--auto` في OpenCode؛ أي صلاحيات ناقصة تُحل في إعدادات OpenCode. عند استخدام مهارات أو تعليمات مخصصة غير المهارة الحالية، تأكد من توفرها في بيئة العامل.

## التخزين والخصوصية

تُحفظ قاعدة المهام والإعدادات وسجل الواجهة في `%LOCALAPPDATA%/WaraqStudio`. تُحفظ النتائج في المجلد المحدد، ونسختها المنظّمة في مجلد المكتبة. المفاتيح في Windows Credential Manager تحت اسم `WaraqStudio`؛ لا تظهر في تصدير الإعدادات. بيانات عمال OpenCode المعزولين في «مجلد بيانات عمال OpenCode»، منفصلة عن بيانات OpenCode الرئيسية.

نتائج كل مهمة داخل مجلد قصير بمعرّف ثابت، ويحتوي الصوت والتفريغ الخام وWord ونسخه. لا يحذف التطبيق النتائج النهائية تلقائيًا. حدود طابور الصوت والمساحة الحرة تمنع التنزيل من ملء القرص.

صوتك يُرسل إلى Deepgram، والتفريغ قد يُرسل إلى مزوّد النموذج الذي يستخدمه OpenCode. سجلات OpenCode المحلية قد تتضمن مقتطفات من المحتوى.

يتضمن الواجهة العربية الفاتحة والداكنة، تحديد القوائم، الطوابير والعمال، الاستئناف، الاستيراد المحلي، نسخ النتائج، وتقرير Excel. أُضيف إلى الإصدار: قوالب البرومبت المتعددة لكل مهمة، الإعادة التلقائية للأخطاء العابرة، إعادة جدولة حد استخدام OpenCode، الإيقاف التلقائي بعد اكتمال الطابور، مزود ونموذج ومستوى تفكير لكل عامل OpenCode مع إضافة مزودين يدويًا وعزل ملفات العمال، فرض إعداد على الطابور عند بدء التشغيل، ومكتبة الملفات المنظّمة بصفحة «الملفات». البحث الحالي في العناوين. البحث داخل النصوص، محرر التفريغ، تقدير الفاتورة، تصدير الترجمة، والتحديث الآلي ليست ضمن هذا الإصدار.

الاستئناف مضمون على مستوى المهمة والاستجابات المحفوظة؛ إضافة المصدر ذاته كدفعة جديدة تنشئ مهام جديدة. لا توجد حاليًا إعادة استخدام عالمية تلقائية لنتائج الدفعات المختلفة.

## التطوير والاختبار

```powershell
python -m pip install -r requirements-dev.txt
python -m pytest -q
python tests/verify_ui.py
python main.py
python build_windows.py
```

الكود الأصلي محفوظ كما هو في مشروعك. التطبيق هنا مستقل ولا يستورده، لتجنب إنشاء سجلات أو أقفال أو آثار جانبية أثناء تحميل الواجهة.

الاختبارات المحلية تستخدم خدمات بديلة لا تستهلك مفاتيح API. يجب إجراء اختبار قبول حي على فيديو تختاره مع إعداداتك قبل الاعتماد على دفعات كبيرة.
